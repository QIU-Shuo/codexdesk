# Support

CodexDesk is an early, community-supported preview.

Before opening an issue:

1. Confirm macOS is running on Apple silicon.
2. Run `codex --version` and verify Codex CLI 0.144.4 or newer is available on
   `PATH`.
3. Run `codex login` and reproduce the problem once after restarting CodexDesk.
4. Search existing GitHub Issues for the same symptom.

For a useful bug report, include the CodexDesk version, macOS version, Codex CLI
version, expected behavior, actual behavior, and minimal reproduction steps.
Remove repository contents, prompts, usernames, paths, tokens, and other private
data from screenshots and logs.

Use GitHub Issues for bugs and narrowly scoped feature requests. This project
does not currently promise response or resolution times.

Do not report vulnerabilities in a public issue. Follow
[SECURITY.md](SECURITY.md) instead.
