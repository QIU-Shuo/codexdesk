# Security Policy

## Supported versions

CodexDesk is an early preview without a stable binary release. Until the
first release, security fixes are made only on the latest `main` branch.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Use the repository's **Security → Advisories → Report a vulnerability** flow:

https://github.com/QIU-Shuo/codexdesk/security/advisories/new

GitHub only offers private vulnerability reporting on public repositories. It
will be enabled immediately after the replacement repository becomes public.
Until then, or if the reporting button is unavailable, open an issue containing
no vulnerability details and ask the maintainer to establish a private contact
channel.

Include affected versions, reproduction steps, impact, and any suggested
mitigation. Please allow the maintainer a reasonable opportunity to investigate
and release a fix before public disclosure.
