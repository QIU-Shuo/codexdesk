# Changelog

All notable CodexDesk changes are documented here.

## 0.1.0 — 2026-08-08

### Added

- Project-grouped, searchable, pinnable, and archivable Codex conversations.
- Streaming chat trajectories for reasoning, plans, tool calls, file changes,
  approvals, queued messages, and steering.
- Repository tree, file viewer, integrated terminal, settings, usage, model,
  reasoning-effort, and approval-mode surfaces.
- New-chat project overview with local/worktree context and branch selection.
- Composer file mentions and slash commands.
- Persisted drafts, layout, appearance, and pre-CodexDesk profile migration.

### Distribution and security

- macOS arm64 application identity and CodexDesk artwork.
- Developer ID signing, notarization, private canary updates, and candidate
  integrity inspection tooling.
- Context-isolated renderer APIs, constrained file access, architecture
  boundary checks, and production dependency auditing.

This version remains a preview and requires a separately installed, signed-in
Codex CLI. CodexDesk is independent from and not endorsed by OpenAI.
